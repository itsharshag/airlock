Airlock

A browser for AI agents that spend money on NEAR

Airlock lets an agent drive any page. Payments outside the agent's key go to a window only you can click, and a dapp whose code changed does not load.

The attacks it stops

A swapped dapp frontend

Airlock hashes every file a pinned dapp serves before the page gets it. If a file changes, Airlock refuses it and blocks signing from that site. Chrome extensions never see a site's files, so they cannot do this.

Bybit lost $1.5B in February 2025 after attackers swapped the Safe{Wallet} JavaScript.

An agent tricked by a page

The agent controls the browser through an API that reaches the page and nothing else. Approvals open in a separate window, and on macOS they also need Touch ID. Airlock refuses to start with remote debugging on.

In May 2026, hidden text in a page drained $175k from an AI agent's wallet.

A poisoned extension update

Airlock has no extensions. The signing guard is part of the browser.

A bad Trust Wallet extension update took about $7M in December 2025.

What happens when a page asks to sign

ALLOW

The request fits the agent's NEAR function-call key, which can call one method on one contract and cannot move NEAR. The agent key signs it.

ASK YOU

The request moves funds, or the receiver is new, barely used, or changed its contract this week. Only the approval window can sign it.

BLOCK

The receiver imitates a known account or is on the blocklist, the request adds a full access key or deletes the account, or the site's code failed its pin.

Try it

git clone https://github.com/itsharshag/airlock && cd airlock && npm install
node scripts/make-account.js     # creates a testnet account from the faucet
node scripts/add-agent-key.js    # adds the agent's function-call key on chain
node scripts/make-payee.js

T=https://airlock-tipjar.itsharshag.com
AIRLOCK_START_URL=$T AIRLOCK_PINS=$T npm start
# In Airlock, sign the guestbook, tip 0.1 NEAR, and open https://airlock-news.itsharshag.com
# Open $T/__attacker/swap?on=1 to swap app.js in your browser only
